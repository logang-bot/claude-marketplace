# Personalities, ingredient by ingredient

Starting points, not prescriptions. Typefaces listed are free on Google Fonts. Every one of them
still obeys the floor rules: weight ≥ 400 for text, contrast ≥ 4.5:1, body text ≥ 16px.

## 1. Serious / Elegant

| Ingredient | Direction |
|---|---|
| Typography | Serif headings with thin strokes at weight 400 (Cormorant Garamond, Playfair Display, Cinzel), often uppercase with wide letter-spacing for short titles; quiet serif or sans body |
| Colour | Gold, champagne, pastels, or near-black and off-white; very few colours |
| Images | Big, high-quality, full-bleed photography; the product as hero |
| Icons | Rare; thin outline if any |
| Shadows | Usually none |
| Border-radius | None — sharp corners read as formal |
| Layout | Generous whitespace, symmetric, slow rhythm, large hero imagery |

## 2. Minimalist / Simple

| Ingredient | Direction |
|---|---|
| Typography | One small/medium sans-serif (Inter, Work Sans, Helvetica-like), black-ish text, often uppercase small titles |
| Colour | Black/near-black and white, one accent at most |
| Images | Few; when present, a single strong image |
| Icons | Few, thin outline |
| Shadows | None |
| Border-radius | None |
| Layout | Lines and boxed sections, strict grid, lots of whitespace, text content first |

## 3. Plain / Neutral

| Ingredient | Direction |
|---|---|
| Typography | Neutral, small sans-serif (Roboto, Open Sans, Source Sans 3, Lato) |
| Colour | Safe, neutral palette with one restrained main colour (often blue) |
| Images | Structured, documentary photos; consistent crops |
| Icons | Standard pack, consistent and unobtrusive |
| Shadows | Usually none, or very subtle |
| Border-radius | Small or none |
| Layout | Very structured grids, boxes and columns, predictable navigation |

## 4. Bold / Confident

| Ingredient | Direction |
|---|---|
| Typography | Big, bold sans-serif headlines (Montserrat, Archivo Black, Space Grotesk, Poppins 700+), uppercase is common, tight leading on big text |
| Colour | Several bright, saturated colours used as large blocks of background |
| Images | Many big images, strong crops |
| Icons | Used freely, filled style |
| Shadows | Usually none — colour blocks carry the emphasis |
| Border-radius | Usually none |
| Layout | Big blocks and full-width sections, strong contrast between sections |

## 5. Calm / Peaceful

| Ingredient | Direction |
|---|---|
| Typography | Soft serif headings (Lora, Libre Baskerville, Fraunces), friendly sans body (Nunito Sans, Mulish) |
| Colour | Pastels and washed-out, desaturated tones; light backgrounds |
| Images | Calm photos and soft illustrations that match the palette |
| Icons | Soft, rounded outline |
| Shadows | Optional, very soft |
| Border-radius | Some, gentle |
| Layout | Airy, centred hero, slow vertical rhythm |

## 6. Startup / Upbeat

| Ingredient | Direction |
|---|---|
| Typography | Medium-sized sans-serif (Inter, Rubik, Manrope, DM Sans), light-grey body text |
| Colour | One confident main colour (blue/indigo/violet are common) plus light-grey backgrounds and a bright accent |
| Images | Many product screenshots, people, and illustrations |
| Icons | Used freely; consistent outline or duotone pack |
| Shadows | Subtle shadows on cards and buttons |
| Border-radius | Rounded buttons, cards and images |
| Layout | Hero with headline + CTA + product image, rows of feature cards, testimonials, pricing |

## 7. Playful / Fun

| Ingredient | Direction |
|---|---|
| Typography | Round sans-serif (Nunito, Quicksand, Baloo 2, Fredoka), large sizes |
| Colour | Many colours, bright and warm |
| Images | Hand-drawn illustrations, characters, patterns |
| Icons | Hand-drawn or rounded, colourful, often enclosed in shapes |
| Shadows | Allowed, including coloured glows |
| Border-radius | Large, pill buttons |
| Layout | Creative but still scannable; animation and fun microcopy |
